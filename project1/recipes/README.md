# Recipe files

Drop Paprika-exported `.html` or `.htm` recipe files in this folder. The app
loads these files from the server when the page opens; reload the page after
adding or removing recipes.

Tags added on the All recipes page are saved automatically in `tags.json`.
Tag colors are saved by tag name, so a color choice is shared wherever that
tag appears.

Use Breakfast, Lunch, or Dinner as a tag to set the recipe's meal type instead
of creating a regular tag.
